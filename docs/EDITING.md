# ตัดต่อและสร้างวิดีโอ

ตอนแรก `001-cat` ยาว 14 วินาที ขนาด 720×1280 ที่ 30 fps (420 เฟรม) ใช้ sprite แมว 16 ท่า ภาพฉากหลัง 1 ภาพ ของตกแต่ง 4 ชิ้น เสียงพากย์ 6 ไฟล์ที่เล่น 7 ครั้ง และเอฟเฟกต์เสียง 3 แบบ

## ทำบน GitHub จากมือถือ

1. เปิดไฟล์ `episodes/001-cat/episode.json` แล้วกดดินสอเพื่อแก้ไข
2. เปลี่ยน `title` / `subtitle` เพื่อแก้ข้อความ หรือ `start` / `end` เพื่อแก้จังหวะ ต้องต่อกันครบ 0–14 วินาที
3. Commit changes ลง branch ของงาน
4. เข้า **Actions → Render episode → Run workflow** เลือก branch และระบุ `001-cat`
5. รอเครื่องหมายเขียว เปิดงานนั้นแล้วดาวน์โหลด **Artifacts → episode-001-cat** ภายในมี MP4, SRT, storyboard, poster และเสียงพากย์

GitHub ทำหน้าที่เก็บไฟล์และรันโค้ดตัดต่อผ่าน Actions ไม่มีหน้าลากคลิปบน timeline แบบ CapCut การแก้ JSON คือการตัดต่อจังหวะ ภาพ และข้อความ ส่วนเสียงรวมและวิดีโอประกอบด้วย FFmpeg

Workflow ทำงานอัตโนมัติเมื่อแก้ไฟล์ผลิตคลิปบน `main` ด้วย ผลที่รันใหม่อยู่ใน Artifacts ไม่เขียนทับไฟล์ exports ใน repository โดยอัตโนมัติ Artifacts เก็บ 30 วัน ส่วน exports ที่ commit ไว้อยู่ในประวัติ Git

## แก้เสียง

ไฟล์เสียงอยู่ใน `episodes/001-cat/audio/` แก้ข้อความพากย์ใน `narration[].text` และลบเฉพาะไฟล์ MP3 ที่ตรงกับข้อความที่เปลี่ยน จากนั้นรัน workflow เพื่อสร้างไฟล์ที่ขาด ระบบเก็บไฟล์เดิมเพื่อให้คลิปที่ทำซ้ำใช้เสียงเดิมได้

`cat.mp3` ใช้ซ้ำสองช่วง ถ้าต้องการคำพูดต่างกันให้ใช้ชื่อไฟล์คนละชื่อ `start` ของ narration เป็นวินาทีจากต้นคลิป ตรวจว่าเสียงจบก่อนเสียงถัดไป โปรแกรมจะหยุดหากเสียงซ้อนหรือยาวเกินตอน

เสียงเป็นเสียงสังเคราะห์: Ana สำหรับอังกฤษและ Premwadee สำหรับไทย บริการสร้างเสียงต้องใช้อินเทอร์เน็ต แต่ไฟล์ที่สร้างและ commit แล้วใช้เรนเดอร์ออฟไลน์ได้ ต้องฟังตรวจคำอ่านเมื่อแก้คำศัพท์ใหม่

## รันบนเครื่อง

ต้องมี Python 3.12, Node.js 20+, FFmpeg/ffprobe และ Pillow ที่มี RAQM สำหรับอักษรไทย

```bash
pip install -r requirements.txt
python scripts/voices.py --episode 001-cat
npm test
python engine/render.py --episode 001-cat
python scripts/check_render.py build/001-cat.mp4
python -m http.server 8000
```

เปิด `http://localhost:8000` เพื่อดูตัวอย่างบนเว็บ มีปุ่มเล่น หยุด เริ่มใหม่ และเลื่อนเวลา เสียงเริ่มเมื่อกดเล่น ไม่มีการเปิด GitHub Pages ให้อัตโนมัติ

## จุดที่แก้ได้

| ข้อมูล | หน้าที่ |
|---|---|
| `scenes[].frames` | หมายเลขท่าแมว เริ่มที่ 0 อ่านซ้ายไปขวา บนลงล่าง |
| `scenes[].rate` | ความเร็วเปลี่ยนท่าต่อวินาที |
| `scenes[].effect` | bounce / think / countdown / reveal / wave / repeat |
| `narration[].start` | เวลาพากย์ |
| `sounds[].gain` | ความดังเอฟเฟกต์ 0–1 |
| `width`, `height`, `fps`, `duration` | ขนาดและเวลาไฟล์วิดีโอ |

Engine รองรับโครงถาม–ทาย–เฉลยของชุดนี้ เปลี่ยนรูปแบบฉากหรือเพิ่มมินิเกมต้องแก้ engine เพิ่ม รูปตัวละครไม่ใช่ lip-sync รายหน่วยเสียง
