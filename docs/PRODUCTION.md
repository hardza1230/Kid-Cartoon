# ผลิตตอนใหม่

1. สร้างโครงด้วย `npm run new:episode -- 002-dog Dog สุนัข`
2. ทำ storyboard 6 ช่วงและเลือกคำที่เด็กเห็นแล้วเข้าใจ
3. สร้าง sprite ของสัตว์นั้นจริงใน `sprites/` ห้ามใช้แมวแทนสัตว์ชนิดอื่น
4. ใส่พาธภาพ ตารางกริด `scenes`, `narration` และ `sounds` ใน episode.json ตามตอน Cat
5. สร้างเสียงด้วย `python scripts/voices.py --episode 002-dog`
6. เพิ่มตอนใน `episodes/index.json` เมื่อไฟล์พร้อม แล้วรัน `npm test`
7. รัน renderer ระบุ `--episode 002-dog` และตรวจวิดีโอด้วย `check_render.py` โดยส่ง JSON ของตอนนั้นเป็น argument ที่สอง
8. เปิดวิดีโอและเว็บตรวจตัวหนังสือไทย ขอบภาพ ความดังและจังหวะก่อนเผยแพร่

การสร้างโครงไม่ลงทะเบียนตอนทันที และไม่เขียนทับโฟลเดอร์เดิม ฉากและของตกแต่งใช้ซ้ำได้ แต่คำศัพท์ ภาพสัตว์และเสียงต้องตรงกัน หน้าเว็บตัวอย่างปัจจุบันเปิดตอน Cat; หากจะเลือกหลายตอนต้องเพิ่มตัวเลือกใน player ก่อน

ผลวิดีโอใหม่บน Actions ดาวน์โหลดเป็น artifact และ commit เข้าโฟลเดอร์ exports ของตอนตามต้องการ ไม่ต้องเก็บเฟรมวิดีโอทุกเฟรมใน Git เพราะสร้างใหม่ได้จากข้อมูลตอน
